# 🎮 五榜 · 第五人格数据站

> 第五人格非官方数据分析页面，提供角色强度榜单、战斗环境解读与上分指南。

**🚀 在线访问：** https://idv-wubang.netlify.app/

---

## ✨ 功能特色

- **角色强度榜单** —— 按八段位划分的角色推荐与强度评级
- **评分模型** —— 基于数据的角色胜率 / 出场率 / 禁用率分析
- **战斗环境全解** —— 版本环境解读，帮助你理解当前 meta
- **环境理解测评** —— 三分钟在线测评工具，测试你的游戏理解
- **版本上分指南** —— 每赛季更新，标注赛区、段位与数据来源

## 📄 页面一览

| 页面 | 说明 |
| --- | --- |
| `index.html` | 首页：角色推荐与战斗环境全解 |
| `character.html` | 角色详情页 |
| `guide.html` | 版本上分指南 |
| `assessment.html` | 环境理解测评工具 |
| `updates.html` | 更新目录 |

## 🛠️ 技术栈

- 原生 HTML / CSS / JavaScript（无框架，轻量加载）
- 纯静态站点，可直接部署到任意静态托管平台

## 🚀 本地运行

```bash
# 任意静态服务器即可，例如：
python -m http.server 8000
# 或使用 VS Code Live Server 插件
```
